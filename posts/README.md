# Blog Posts Directory

This directory contains all the blog posts for your GitBlog instance.

## Post Format

Posts should be written in Markdown with YAML frontmatter. Example:

```markdown
---
title: Getting Started with React Hooks
author: John Doe
date: 2025-05-01
tags: [react, javascript, webdev]
image: https://example.com/image.jpg
excerpt: Learn how to use React Hooks to write cleaner components.
slug: getting-started-with-react-hooks
---

# Getting Started with React Hooks

Content goes here...
```
