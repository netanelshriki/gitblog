# GitBlog - GitHub-based Modern Blogging Platform

GitBlog is a beautiful, feature-rich blogging platform that uses GitHub as its database, allowing you to manage your content through Git while providing an elegant interface for your readers.

## Features

- **GitHub-powered Content Management**: Store all your posts directly in your GitHub repository as markdown files
- **Beautiful UI**: Modern, responsive design with animations and smooth transitions
- **Dark/Light Mode**: Built-in theme switching for optimal reading experience
- **Code Syntax Highlighting**: Beautiful code blocks with language-specific highlighting
- **Authentication & Authorization**: GitHub OAuth integration for login, with role-based access
- **Markdown Support**: Write your posts in markdown with frontmatter for metadata
- **Tag System**: Organize content with tags and filter posts by tag
- **Search Functionality**: Full-text search across all your posts
- **Commenting System**: Allow readers to engage with your content
- **Admin Dashboard**: Manage your posts, users, and site settings
- **Responsive Design**: Looks great on all devices from mobile to desktop
- **SEO Optimized**: Built with search engines in mind

## Quick Start

1. Fork this repository
2. Enable GitHub Pages in your repository settings
3. Update the repository configuration in `index.html`
4. Create a GitHub OAuth application and update the CLIENT_ID
5. Start writing posts in your `posts` directory
